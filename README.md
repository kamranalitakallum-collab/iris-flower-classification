# Iris Flower Classification using Random Forest

An end-to-end Machine Learning project that classifies Iris flower species based on sepal and petal measurements using a Random Forest Classifier.

## 📂 Project Structure
- `iris.csv`: The dataset containing Iris flower features and species labels.
- `iris_classification_rf.ipynb`: Jupyter notebook containing EDA, data preprocessing, model training, evaluation, and hyperparameter tuning (GridSearchCV).
- `requirements.txt`: List of required Python packages.

## 🚀 Technologies & Libraries Used
- **Python**
- **Pandas & NumPy** (Data manipulation)
- **Scikit-Learn** (Random Forest, Metrics, GridSearchCV)
- **Matplotlib** (Visualizations & Confusion Matrix)
- **Joblib** (Model serialization)

## 📊 Model Performance
- Achieved high accuracy with optimized hyperparameters using `GridSearchCV`.
- Evaluated using Confusion Matrix and Classification Report.
